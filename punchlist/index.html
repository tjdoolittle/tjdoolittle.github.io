Your job calendar, as a checklist for every tech.

The office keeps scheduling in Google Calendar the way it does now. Each tech opens one link on their phone and sees today's jobs, the address, the gate code, and a checklist built from the event notes plus your standard steps for that kind of job. Every check-off is logged to a Google Sheet.

Built from how crews already work

I made this for the install techs at an AV and home automation company. Jobs were already on a shared calendar with the tech's initials in the title, so the app reads that instead of asking anyone to change.

Set up from a spreadsheet

The office manages everything in a Google Sheet. Adding a tech or a checklist is a new row, not a code change.

Techs

Name, the tag used in event titles, and their Google email. Their own tab opens first when they sign in. Managers get a view of everyone.

Checklists

Keyword and task, one row each. Every job that mentions the keyword gets those steps, with a small label so techs know where they came from.

Log

Each check-off with the job, the task, the time and who did it. Sort it, filter it, or build a report from it.

Set it up in about 10 minutes

You need a Google account that can see the job calendar. Works with Google Workspace or a personal Gmail.

  1. Make the sheetCopy the template, or make a new sheet and paste the two files from GitHub into Extensions > Apps Script.
  2. Run Punchlist > Set up sheetIt adds the Settings, Techs, Checklists and Log tabs with examples.
  3. Fill in your calendar and techsThen Punchlist > Test my calendar shows how many jobs it found for each person.
  4. Deploy as a web appExecute as you, open to your organization. Send the link and have techs add it to their home screen.
